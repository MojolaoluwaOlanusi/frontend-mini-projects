# German Flag

CSS recreation of the German flag with horizontal stripes.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Stripe elements
- Simple, semantic structure

### CSS Concepts
- Flexbox for vertical layout
- Equal height distribution
- Flag color schemes (black, red, gold)
- Container sizing
- Horizontal stripe patterns

### Key Techniques
- Creating horizontal flag designs
- Using flexbox for stripes
- Understanding flag proportions
- Color coordination
- Container-based layouts

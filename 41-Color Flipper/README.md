# Color Flipper

Interactive color flipper that changes background colors randomly.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling for the color flipper
- `index.js` - JavaScript for color generation

## 🎯 What You'll Learn

### HTML Concepts
- Simple page structure
- Button element
- Text display for color code
- Semantic structure

### CSS Concepts
- Transition effects
- Container styling
- Button styling
- Display styling
- Background color transitions

### JavaScript Concepts
- Random color generation
- DOM manipulation
- Event listeners
- Color code display
- Background color changes
- Math.random() usage

### Key Techniques
- Creating interactive color tools
- Random color generation
- DOM manipulation
- Event handling
- Color code formatting

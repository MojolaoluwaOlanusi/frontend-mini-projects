# Toggle Switch

A functional toggle switch component using checkbox.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the toggle switch

## 🎯 What You'll Learn

### HTML Concepts
- Checkbox input element
- Label element for wrapping
- Custom checkbox styling
- Accessible form elements

### CSS Concepts
- Hiding default checkbox
- Pseudo-elements (::before, ::after)
- Custom toggle switch design
- Positioning techniques
- Transition effects
- Checked state styling
- Interactive UI components

### Key Techniques
- Creating custom form controls
- Using pseudo-elements
- Styling checked states
- Building interactive switches
- Smooth transitions

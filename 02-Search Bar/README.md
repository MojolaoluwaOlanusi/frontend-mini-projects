# Search Bar

A clean and modern search input field with placeholder text.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the search bar

## 🎯 What You'll Learn

### HTML Concepts
- Input element with type="search"
- Label element for accessibility
- Placeholder text
- ID attributes for targeting

### CSS Concepts
- Input field styling
- Removing default browser styles
- Placeholder text customization
- Border and border-radius
- Padding and sizing
- Focus states for accessibility
- Container centering

### Key Techniques
- Creating accessible form inputs
- Styling search fields
- Implementing focus states
- Proper labeling for screen readers

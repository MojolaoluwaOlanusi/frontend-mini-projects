# Neon Effect Navbar

Neon-styled navigation bar with icons and glow effects.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling with neon effects
- SVG icons (facebook.svg, file.svg, globe.svg, window.svg, x.svg)

## 🎯 What You'll Learn

### HTML Concepts
- Navigation structure (nav)
- List-based menus
- SVG icon integration
- Link elements
- Semantic navigation markup

### CSS Concepts
- Navbar layout design
- Neon glow effects
- Flexbox for navigation
- Icon styling
- Hover effects
- Background images
- Glow animations

### Key Techniques
- Building navigation bars
- Neon effect implementation
- SVG icon integration
- Flexbox nav layouts
- Hover animations

# Github Profile

GitHub-style profile card with avatar, name, username, and edit button.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the profile card

## 🎯 What You'll Learn

### HTML Concepts
- Profile card structure
- Image elements for avatar
- Heading hierarchy (h2, h3)
- Button element
- Semantic text structure

### CSS Concepts
- Card layout design
- Image sizing and circular avatar
- Flexbox for profile layout
- Typography hierarchy
- Button styling
- Container sizing and centering
- Shadow effects

### Key Techniques
- Building profile cards
- Creating circular avatars
- Flexbox layouts for profiles
- Typography hierarchy
- Button design

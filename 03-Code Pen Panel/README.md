# Code Pen Panel

A card component displaying project information with thumbnail, avatar, and stats.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the card component

## 🎯 What You'll Learn

### HTML Concepts
- Card layout structure
- Image elements for thumbnails and avatars
- Nested divs for component organization
- List elements for stats
- Heading and paragraph tags

### CSS Concepts
- Card layout design
- Image sizing and positioning
- Flexbox for internal layout
- Border-radius for rounded corners
- Shadow effects for depth
- Typography hierarchy
- Responsive card design

### Key Techniques
- Building card components
- Handling images in cards
- Creating visual hierarchy
- Flexbox layouts for complex components
- Adding depth with shadows

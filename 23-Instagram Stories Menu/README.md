# Instagram Stories Menu

Instagram-style stories menu with circular avatar images and status indicators.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the stories menu

## 🎯 What You'll Learn

### HTML Concepts
- List structure (ul, li)
- Image elements for avatars
- Wrapper divs for styling
- Status classes (new, viewed, live)
- Semantic structure

### CSS Concepts
- Circular image styling
- Border styling for status
- List layouts with flexbox
- Avatar sizing
- Status indicator colors
- Container spacing

### Key Techniques
- Creating story menus
- Circular avatar design
- Status indicator styling
- List-based layouts
- Social media UI patterns

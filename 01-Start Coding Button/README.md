# Start Coding Button

A simple button component with styled border effects.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the button

## 🎯 What You'll Learn

### HTML Concepts
- Button element (`<button>`)
- Container divs for layout structure
- Semantic HTML structure

### CSS Concepts
- Button styling and customization
- Border manipulation and effects
- Flexbox for centering
- Hover effects
- Background colors and gradients
- Padding and margin for spacing
- Font styling and typography

### Key Techniques
- Creating attractive button designs
- Using container divs for layout
- Implementing hover states
- Centering elements with flexbox

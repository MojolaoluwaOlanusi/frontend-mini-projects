# Japanese Flag

CSS recreation of the Japanese flag with centered red circle.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Circle element
- Simple, semantic structure

### CSS Concepts
- Absolute positioning
- Centering elements
- Border-radius for circles
- Background colors (white, red)
- Container sizing
- Perfect centering techniques

### Key Techniques
- Creating circle designs
- Centering elements perfectly
- Understanding flag proportions
- Minimalist design
- Precise positioning

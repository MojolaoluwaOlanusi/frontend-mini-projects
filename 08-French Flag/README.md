# French Flag

CSS recreation of the French flag with vertical stripes.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Stripe elements
- Simple, semantic structure

### CSS Concepts
- Flexbox for horizontal layout
- Equal width distribution
- Flag color schemes
- Container sizing
- Border styling

### Key Techniques
- Creating flag designs with CSS
- Using flexbox for stripes
- Understanding flag proportions
- Color coordination
- Container-based layouts

# Archery Target

Concentric circles creating an archery target pattern using nested divs.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the target

## 🎯 What You'll Learn

### HTML Concepts
- Nested div structure
- Multiple ring elements
- Bulleye center element

### CSS Concepts
- Absolute positioning
- Nested element styling
- Border-radius for circles
- Centering within parent
- Z-index for layering
- Color coordination

### Key Techniques
- Creating concentric circles
- Using absolute positioning
- Layering elements with z-index
- Centering nested elements
- Building geometric shapes

# Neon Progress Bar

Animated neon progress bar with JavaScript-driven animations.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling with neon effects
- `script.js` - JavaScript for progress animation

### JavaScript Concepts

- Width manipulation
- setInterval usage
- DOM manipulation
- State management

### Key Techniques
- Creating neon progress bars
- JavaScript-driven animations
- Glow effect design
- Progress visualization
- Animation timing

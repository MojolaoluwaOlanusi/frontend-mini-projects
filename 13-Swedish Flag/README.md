# Swedish Flag

CSS recreation of the Swedish flag with cross design.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Cross elements
- Simple, semantic structure

### CSS Concepts
- Absolute positioning for cross
- Background color (blue)
- Cross design with yellow
- Positioning elements precisely
- Container sizing
- Cross proportions

### Key Techniques
- Creating Nordic cross designs
- Using absolute positioning
- Understanding flag proportions
- Color coordination
- Precise element positioning

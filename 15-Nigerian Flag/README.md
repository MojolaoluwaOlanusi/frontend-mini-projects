# Nigerian Flag

CSS recreation of the Nigerian flag with vertical green-white-green stripes.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Stripe elements
- Simple, semantic structure

### CSS Concepts
- Flexbox for horizontal layout
- Equal width distribution
- Flag color schemes (green, white)
- Container sizing
- Vertical stripe patterns

### Key Techniques
- Creating vertical flag designs
- Using flexbox for stripes
- Understanding flag proportions
- Color coordination
- Symmetric layouts

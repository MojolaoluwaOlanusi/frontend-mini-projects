# Loading Squares

Animated loading squares with staggered animations for a dynamic effect.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling and animations

## 🎯 What You'll Learn

### HTML Concepts
- Container div for animation
- Multiple square elements with different classes
- Simple, clean structure

### CSS Concepts
- Keyframe animations for scaling
- Animation delays for staggered effects
- Square sizing with width/height
- Color transitions
- Transform properties (scale)
- Flexbox for layout

### Key Techniques
- Creating staggered animations
- Using transform: scale()
- Implementing animation delays
- Creating dynamic loading states
- Combining multiple animated elements

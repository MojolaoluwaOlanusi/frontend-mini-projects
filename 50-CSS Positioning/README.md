# CSS Positioning

A demonstration of CSS positioning methods.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling with CSS positioning

## 🎯 What You'll Learn

### HTML Concepts
- Box elements
- Container structure
- Semantic markup

### CSS Concepts
- position: relative
- position: absolute
- position: fixed
- position: sticky
- top, right, bottom, left properties
- Positioning context

### Key Techniques
- Understanding positioning contexts
- Relative positioning for offsets
- Absolute positioning for precise placement
- Fixed positioning for sticky elements
- Sticky positioning for scroll effects

# Word Carousel

Text carousel that cycles through different words using CSS animations.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling and animations

## 🎯 What You'll Learn

### HTML Concepts
- Simple heading structure
- Container for text animation
- Clean, minimal markup

### CSS Concepts
- Text animations
- Keyframe animations for text changes
- Opacity transitions
- Timing functions
- Animation iteration
- Typography styling

### Key Techniques
- Creating text transitions
- Using opacity for fade effects
- Implementing infinite animations
- Timing text changes
- Creating dynamic text effects

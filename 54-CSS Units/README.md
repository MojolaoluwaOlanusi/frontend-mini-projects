# CSS Units

A demonstration of different CSS units for sizing.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling with CSS units

## 🎯 What You'll Learn

### HTML Concepts
- Box elements
- Container structure
- Semantic markup

### CSS Concepts
- px (pixels)
- rem (root em)
- em (relative to parent)
- % (percentage)
- vh (viewport height)
- vw (viewport width)
- Responsive sizing
- Unit selection

### Key Techniques
- Understanding different units
- Absolute vs relative units
- Responsive design with viewport units
- Typography scaling with rem/em
- Choosing appropriate units

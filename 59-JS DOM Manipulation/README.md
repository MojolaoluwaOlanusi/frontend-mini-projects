# JS DOM Manipulation

A demonstration of JavaScript DOM manipulation techniques.

## 📁 Files
- `index.html` - HTML structure
- `style.css` - Styling
- `script.js` - JavaScript DOM manipulation

## 🎯 What You'll Learn

### HTML Concepts
- Interactive elements
- Dynamic content areas
- Semantic structure

### CSS Concepts
- Button styling
- Dynamic styling
- Transition effects
- Element positioning

### JavaScript Concepts
- DOM selection (querySelector, getElementById)
- Changing text content
- Modifying styles
- Adding/removing elements
- Attribute manipulation
- Class manipulation
- Event handling

### Key Techniques
- Selecting DOM elements
- Modifying element content
- Dynamic styling
- Creating and removing elements
- DOM event handling
- Manipulating attributes and classes

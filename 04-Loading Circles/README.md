# Loading Circles

Animated loading circles using CSS keyframe animations.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling and animations

## 🎯 What You'll Learn

### HTML Concepts
- Container div for loading animation
- Multiple circle elements
- Simple, semantic structure

### CSS Concepts
- Keyframe animations (`@keyframes`)
- Animation properties (duration, timing-function, iteration)
- Border-radius for perfect circles
- Staggered animation delays
- Opacity and color transitions
- Centering with flexbox

### Key Techniques
- Creating loading indicators
- Using keyframe animations
- Implementing animation delays
- Creating smooth, repeating animations
- Timing functions for different effects

# 4 of Hearts

CSS recreation of a playing card (4 of Hearts) with suit symbols.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the card

## 🎯 What You'll Learn

### HTML Concepts
- Card container structure
- Left, middle, right sections
- Unicode symbols (&hearts;)
- Multiple symbol placement
- Semantic structure

### CSS Concepts
- Card layout design
- Grid or flexbox for suits
- Absolute positioning
- Typography sizing
- Centering techniques
- Card proportions
- Symbol grid layouts

### Key Techniques
- Creating playing card layouts
- Grid layouts for suit symbols
- Positioning multiple elements
- Card design patterns
- Section-based layouts

# Progress Bar

Static progress bar component showing completion status.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the progress bar

## 🎯 What You'll Learn

### HTML Concepts
- Progress bar container
- Progress status element
- Simple, semantic structure

### CSS Concepts
- Progress bar container styling
- Width percentages for progress
- Background colors
- Border-radius for rounded bars
- Container sizing
- Color coordination

### Key Techniques
- Creating progress indicators
- Using width percentages
- Designing progress bars
- Color coding progress
- Container-based layouts

# Loading Spinner

Animated loading spinner using border-radius tricks.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling and animations

## 🎯 What You'll Learn

### HTML Concepts
- Container div
- Spinner element
- Simple, minimal structure

### CSS Concepts
- Border-radius for circles
- Border styling (transparent borders)
- Rotation animations
- Keyframe animations
- Spinner design patterns
- Animation timing

### Key Techniques
- Creating circular loaders
- Using border tricks
- Rotation animations
- Loading indicator design
- Animation timing functions

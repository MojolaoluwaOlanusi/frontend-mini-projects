# Madagascar Flag

CSS recreation of the Madagascar flag with vertical and horizontal stripes.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Nested stripe elements
- Complex flag structure

### CSS Concepts
- Combining flexbox layouts
- Mixed vertical/horizontal stripes
- Flag color schemes (white, red, green)
- Container sizing
- Complex grid layouts

### Key Techniques
- Creating complex flag designs
- Mixing layout directions
- Understanding flag proportions
- Color coordination
- Nested container layouts

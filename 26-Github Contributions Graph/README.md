# Github Contributions Graph

GitHub-style contributions graph with multiple colors representing activity levels.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the graph
- `index.js` - JavaScript for dynamic generation

## 🎯 What You'll Learn

### HTML Concepts
- Graph container structure
- Legend elements
- Grid container
- Semantic structure

### CSS Concepts
- Grid layouts
- Dynamic element styling
- Color coordination (multiple shades)
- Container sizing
- Legend styling
- Grid cell styling

### JavaScript Concepts
- Dynamic element creation
- Loop for generating cells
- Conditional color assignment
- DOM manipulation
- Array manipulation
- Random data generation

### Key Techniques
- Creating contribution graphs
- Dynamic element generation
- Conditional styling
- Grid layouts
- Data visualization with multiple colors

# Frontend Mini Projects

A collection of frontend web development projects designed to help developers learn and practice HTML, CSS, and JavaScript concepts. This repository contains projects ranging from basic CSS challenges to interactive web applications, perfect for beginners and intermediate developers looking to enhance their skills.

## 📚 Projects Overview

### CSS Fundamentals (01-26)

A simple button with styled border effects. Learn about button styling, border manipulation, and basic CSS positioning.

#### 02-Search Bar
A clean search input field with placeholder text. Learn about form inputs, labeling, and input styling.

#### 03-Code Pen Panel
A card component displaying project information with thumbnail and avatar. Learn about card layouts, image handling, and flexbox positioning.

#### 04-Loading Circles
Animated loading circles using CSS animations. Learn about keyframe animations, timing functions, and creating loading indicators.

#### 05-Loading Squares
Animated loading squares with staggered animations. Learn about animation delays and creating dynamic loading states.

#### 06-Archery Target

#### 07-Word Carousel

## 🎯 Learning Path

1. **Start with CSS Fundamentals (01-26)**: Begin with basic styling and progressively learn about layouts, animations, and complex designs.
2. **Move to Advanced Projects (27-38)**: Apply your CSS knowledge to build interactive applications with JavaScript functionality.
3. **Practice and Experiment**: Modify existing projects to understand concepts better and create your own variations.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Styling, animations, and responsive design
- **JavaScript**: Interactive functionality and DOM manipulation
- **CSS3 Features**: Flexbox, Grid, Transforms, Transitions, Animations, Glassmorphism, Neon effects

## 📝 How to Use

1. Clone this repository
2. Navigate to any project folder
3. Open the `index.html` file in your browser
4. Explore the code to understand how it works
5. Modify and experiment with the code to learn

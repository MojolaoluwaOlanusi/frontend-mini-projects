# Niger Flag

CSS recreation of the Niger flag with horizontal stripes and center circle.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Stripe elements
- Circle element within stripe
- Nested structure

### CSS Concepts
- Flexbox for horizontal layout
- Absolute positioning for circle
- Flag color schemes (orange, white, green)
- Combining shapes
- Container sizing

### Key Techniques
- Creating complex flag designs
- Combining stripes and circles
- Using absolute positioning
- Understanding flag proportions
- Color coordination

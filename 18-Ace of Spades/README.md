# Ace of Spades

CSS recreation of a playing card (Ace of Spades) with proper positioning.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the card

## 🎯 What You'll Learn

### HTML Concepts
- Card container structure
- Top, center, bottom sections
- Unicode symbols (&spades;)
- Number and symbol placement
- Semantic structure

### CSS Concepts
- Card layout design
- Absolute positioning
- Flexbox for sections
- Typography sizing
- Centering techniques
- Card proportions
- Symbol positioning

### Key Techniques
- Creating playing card layouts
- Positioning elements precisely
- Using Unicode symbols
- Card design patterns
- Section-based layouts

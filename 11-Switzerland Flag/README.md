# Switzerland Flag

CSS recreation of the Swiss flag with cross design.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling for the flag

## 🎯 What You'll Learn

### HTML Concepts
- Container div for flag
- Cross elements (horizontal and vertical)
- Simple, semantic structure

### CSS Concepts
- Absolute positioning for cross
- Background color (red)
- Cross design with white
- Positioning elements precisely
- Container sizing

### Key Techniques
- Creating cross designs
- Using absolute positioning
- Understanding flag proportions
- Color coordination
- Precise element positioning

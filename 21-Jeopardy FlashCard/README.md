# Jeopardy FlashCard

Flip card component with front and back faces for quiz-style content.

## 📁 Files
- `index.html` - HTML structure
- `index.css` - Styling and 3D transforms

## 🎯 What You'll Learn

### HTML Concepts
- Card container structure
- Front and back faces
- Question and answer content
- Semantic structure

### CSS Concepts
- 3D transforms (rotateY)
- Perspective property
- Backface-visibility
- Card flip animations
- Hover effects
- 3D space manipulation

### Key Techniques
- Creating flip cards
- Using 3D transforms
- Implementing perspective
- Card flip animations
- 3D CSS techniques
